# María Perarnau - Portfolio Web

Este es el portfolio web de **María Perarnau**, una desarrolladora de videojuegos, artista conceptual y artista 3D. La página muestra proyectos, información personal y formas de contacto.

## 🖥 Tecnologías utilizadas

- HTML5
- CSS3 (con animaciones y efectos personalizados)
- JavaScript (para interacción con el DOM y cambio de videos)
- Recursos multimedia (videos, íconos, imágenes)

## 🚀 Funcionalidades principales

- Sección de introducción con animaciones suaves y botón central
- Fondo dinámico
- Reproductor de video en bucle con efecto de transición (crossfade)
- Secciones de contacto con redes sociales
- Diseño responsive y visualmente atractivo
